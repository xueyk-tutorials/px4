## 别名定义

PX4启动后需要创建各模块运行线程，为了避免px4内的模块名与Linux内的程序冲突，需要将要启动的线程定义别名，故需要先运行别名定义脚本。

```sh
# PX4 commands need the 'px4-' prefix in bash.
# (px4-alias.sh is expected to be in the PATH)
# shellcheck disable=SC1091
. px4-alias.sh
```

通过`/build/bin/px4-alias.sh`文件设置各模块的别名，将各模块线程添加了`px4-`前缀，例如`px4-commander`就是指commander模块。

```sh
alias commander='px4-commander --instance $px4_instance'
```

> 在cmake阶段，在运行platforms/posix/CMakeLists.txt时，调用函数px4_posix_generate_alias()，基于`platforms/posix/src/px4/common/px4-alias.sh_in`生成`/build/bin/px4-alias.sh`文件。

## 设置环境变量PATH

在Linux系统中，**`${PATH}`** 是一个**环境变量**，用于指定系统在哪些目录中查找可执行文件（如命令或脚本）。其核心作用是为用户和程序提供一种便捷的方式去运行命令，而无需输入完整的文件路径。

当PX4完成posix编译后，就会将启动脚本拷贝至`build/px4_sitl_default/etc/init.d-posix`下，将该目录添加至`PATH`环境变量后就可以直接运行这些脚本了。

```bash
PATH="$PATH:${R}etc/init.d-posix"
```
